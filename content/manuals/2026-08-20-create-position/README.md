# Как создать должность

- Тема: «Как создать должность?»
- Функция: создание должности и назначение её сотруднику
- Дата: 20.08.2026
- Формат: 7 карточек, 1080 × 1080 px
- Следующая рекомендуемая тема: «Как настроить права должности?»

## Карточки

1. `01-cover.png` — обложка и точка входа.
2. `02-step.png` — переход из блока «Разделы» в «Должности».
3. `03-step.png` — кнопка «+ Создать».
4. `04-step.png` — обязательные поля «Название должности» и «Сотрудник».
5. `05-step.png` — «Профиль зарплаты», «Шаблон прав» и «Применить шаблон».
6. `06-step.png` — кнопка «Сохранить».
7. `07-result.png` — уведомление «Должность создана» и новая запись в списке.

## Проверено по текущему интерфейсу

- Страница заведения: кнопка «Должности» в блоке «Разделы».
- Страница «Должности»: блок «Список должностей» и primary-кнопка «+ Создать».
- Модальное окно «Создать должность».
- Обязательные поля: «Название должности» и «Сотрудник».
- Дополнительные настройки: «Профиль зарплаты», «Начисление», «Шаблон прав» и кнопка «Применить шаблон».
- Финальные действия: primary-кнопка «Сохранить» и обычная кнопка «Отмена».
- Успешный результат: уведомление «Должность создана» и новая группа должности в списке.
- В строке должности сохранены реальные подписи: «+ Добавить сотрудника», «Изменить», «Архивировать».

Интерфейс сверялся с актуальным локальным E2E-стендом Axelio и текущими файлами `frontend/positions.js` и `frontend/positions/position-editor.js`. Реальная должность не создавалась: заполнение формы использовалось только для визуальной проверки, без нажатия «Сохранить».

## Визуальная сборка

Все пошаговые карточки используют ту же фиксированную сетку, что и одобренный гайд `2026-08-13-invite-employee`:

- номер шага: `(64, 50, 124, 110)`;
- начало заголовка: `(64, 137)`;
- начало пояснения: `(64, 230)`;
- внешняя рамка интерфейса: `(60, 315, 1020, 930)`;
- нижняя подсказка начинается с `y = 950`.

Стрелки не использованы: один целевой элемент на каждом шаге выделен фиолетовой рамкой. Стиль кнопок повторяет интерфейс: primary — синий, обычная `.btn` — тёмная контурная, danger — красная.

Тематическая 3D-иллюстрация обложки создана встроенным ImageGen. Prompt set: мягкая white/lavender clay-эстетика, бейдж сотрудника, портфель и шестерёнка с отметкой; без текста, логотипов и водяных знаков. Итоговые слайды собраны воспроизводимым проектным скриптом и сохранены в 1080 × 1080 px.
