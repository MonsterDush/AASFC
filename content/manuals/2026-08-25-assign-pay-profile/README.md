# Как назначить профиль зарплаты сотруднику

- Тема: «Как назначить профиль зарплаты сотруднику?»
- Функция: создание назначения профиля зарплаты для участника заведения
- Дата: 25.08.2026
- Формат: 8 карточек, 1080 × 1080 px
- Следующая рекомендуемая тема: «Как проверить начисления сотрудника?»

## Карточки

1. `01-cover.png` — обложка и точка входа.
2. `02-step.png` — переход из блока «Финансы» в «Профили зарплаты».
3. `03-step.png` — открытие нужного профиля обычной кнопкой «Открыть».
4. `04-step.png` — блок «Назначения» и primary-кнопка «+ Назначить».
5. `05-step.png` — выбор сотрудника в форме «Новое назначение».
6. `06-step.png` — поля «Дата начала», «Дата окончания» и состояние «Назначение активно».
7. `07-step.png` — primary-кнопка «Сохранить».
8. `08-result.png` — уведомление «Назначение создано» и готовая строка сотрудника.

## Использованные реальные экраны

- страница заведения, блок «Финансы»;
- страница «Профили зарплаты»;
- карточка профиля «Бар и зал»;
- блок «Назначения»;
- форма «Новое назначение»;
- результат с назначением профиля сотруднику.

Локальный E2E-маршрут проверен на профиле «Бар и зал». В форме выбран сотрудник «София», указана дата начала `2026-08-25`, дата окончания оставлена пустой. После сохранения интерфейс показал уведомление «Назначение создано» и строку `2026-08-25 → без даты окончания`. Изменения выполнялись только в одноразовой локальной E2E-базе, которая удаляется после проверки; производственные данные не затрагивались.

## Визуальная сборка

Все пошаговые карточки используют фиксированную геометрию серии:

- круг с номером: `(64, 50, 124, 110)`;
- подпись шага начинается в `(145, 64)`;
- начало заголовка: `(64, 137)`;
- начало пояснения: `(64, 230)`;
- внешняя рамка интерфейса: `(60, 315, 1020, 930)`;
- нижняя подсказка начинается с `y = 950`.

Сетка и helpers унаследованы от выпусков `2026-08-13-invite-employee` и `2026-08-20-pay-profile`. Инструкционные стрелки не использованы: целевые контролы выделены фиолетовыми рамками. Символ `→` оставлен только внутри дословной строки периода из интерфейса. Primary-кнопки показаны синими, обычная `.btn` — тёмной контурной, danger — красной. Подписи кнопок не переносятся на вторую строку.

Тематическая 3D-иллюстрация обложки создана встроенным ImageGen. Prompt set: карточка профиля, аватар сотрудника и календарь с отметкой в мягкой white/lavender clay-эстетике Axelio; без текста, логотипов, водяных знаков и стрелок. Финальные карточки собраны воспроизводимым скриптом `build_guide.py`.
