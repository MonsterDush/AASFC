# Как отключить правило регулярного расхода

- Тема: остановка будущих регулярных расходов без удаления правила.
- Функция: редактирование правила регулярного расхода и переключение `is_active` в выключенное состояние.
- Дата: 2026-10-02.
- Формат: 8 квадратных слайдов, 1080×1080, RGB.
- Следующая рекомендуемая тема: «Как изменить сумму и расписание регулярного расхода?»

## Реальные экраны Axelio

1. Страница заведения, блок «Финансы» → «Расходы».
2. «Расходы», блок «Справочники и быстрые действия» → карточка «Регулярные расходы».
3. Список «Регулярные расходы» с существующим активным правилом.
4. Модальное окно «Редактировать правило».
5. Список после сохранения: статус «Выключено», счётчик «Активных» равен 0.

## Проверка сценария

Сценарий воспроизведён в изолированном локальном E2E Axelio на заведении `Axelio E2E Lounge` за октябрь 2026 года. Создано правило «Аренда склада» на 135 000,00 ₽, затем оно обновлено с `is_active=true` на `is_active=false`. API вернул `is_active=false`; в базе сохранено выключенное состояние. Производственные данные не использовались.

## Визуальная сборка

Слайды собраны скриптом `build_guide.py` на Pillow с переиспользованием компонентов одобренной серии. На шагах 1–6 зафиксированы координаты номера, подписи «ШАГ N», заголовка, пояснения, внешней UI-рамки и нижней подсказки. Главный контрол выделяется одной рамкой; стрелки не используются.

Запуск:

```bash
PYTHONDONTWRITEBYTECODE=1 python3 content/manuals/2026-10-02-disable-recurring-expense-rule/build_guide.py
```

Скрипт проверяет размер, RGB, совпадение сетки с предыдущим выпуском, отсутствие стрелок и наличие интерфейсных строк в текущем коде.
