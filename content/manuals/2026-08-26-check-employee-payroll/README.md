# Как проверить начисления сотрудника?

- Дата: 2026-08-26
- Функция: просмотр расчёта зарплаты и детализации начисления сотрудника
- Формат: Instagram-карусель, 8 отдельных изображений 1080×1080
- Следующая рекомендуемая тема: «Как выгрузить начисления в XLSX?»

## Реальный пользовательский маршрут

1. Страница заведения → блок «Финансы» → «Начисления».
2. «Расчёт зарплаты» → «Период начислений» → режим «Месяц» → август 2026 года.
3. Сводные показатели расчёта.
4. Блок «Начисления сотрудникам» → строка Софии.
5. «Показать разбор» → составляющие начисления и итог.

Маршрут проверен в локальном E2E Axelio на синтетических данных. Производственные действия не выполнялись. В карусели показан уже готовый расчёт; кнопка «Рассчитать» не нажималась.

## Использованные реальные экраны

- `frontend/app-venue.html` — вход в раздел «Начисления» из блока «Финансы»;
- `frontend/owner-payroll.html` и `frontend/owner-payroll.js` — период, сводка, список сотрудников и раскрытый разбор;
- локальный E2E-экран `owner-payroll.html?venue_id=1&month=2026-08&lang=ru` — значения расчёта и визуальная иерархия контролов.

## Визуальная сборка

- Слайды собраны кодом в `build_guide.py` через Pillow.
- Декоративная иллюстрация обложки создана встроенным ImageGen в режиме по умолчанию; она не подменяет интерфейсные экраны.
- Рабочие фрагменты реконструированы по текущему UI Axelio: обычные `.btn` показаны тёмными/контурными, `Рассчитать` — синей primary-кнопкой.
- Инструкционные стрелки не используются: на каждом шаге достаточно одной фиолетовой рамки вокруг целевого элемента.
- На шагах 1–6 сохранена сетка серии: номер шага `(64, 50, 124, 110)`, «ШАГ N» `(145, 64)`, заголовок `(64, 137)`, пояснение `(64, 230)`, UI-зона `(60, 315, 1020, 930)`, нижняя подсказка `y=950`.
- Геометрия сопоставлена с `content/manuals/2026-08-13-invite-employee` и программно проверяется против общей сетки серии.
