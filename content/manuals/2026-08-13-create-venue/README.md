## Проверка сценария

Сценарий проверен 13.08.2026 по текущему коду и локальному E2E-интерфейсу Axelio. Для первого заведения интерфейс обещает 3 дня полного пробного доступа и переход в «Быструю настройку». Последующие заведения создаются без trial и открываются на странице заведения и оплаты.

Финальная карусель сгенерирована встроенным ImageGen в режиме `ui-mockup` по реальным экранам Axelio. Prompt set: квадратный help-center стиль серии; светлый фон с тонкой сеткой; тёмно-синие заголовки; фиолетовые акценты; один выделенный контрол на слайд; точные русские строки и текущие элементы интерфейса. Слайды механически нормализованы до 1080 × 1080 px без повторной композиционной сборки.
