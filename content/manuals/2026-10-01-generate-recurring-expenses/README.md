# Как сгенерировать расходы по правилам за месяц?

- Дата: 2026-10-01
- Функция: массовая генерация черновиков расходов по активным регулярным правилам за выбранный месяц.
- Формат: Instagram-карусель, 9 квадратных слайдов 1080×1080.

## Реальный маршрут

1. Раздел «Финансы» → «Расходы».
2. «Справочники и быстрые действия» → «Регулярные расходы» → «Открыть».
3. Выбор месяца в верхней панели страницы «Регулярные расходы».
4. Проверка активного правила → «Сгенерировать за месяц».
5. Блок «Результат последней генерации» → «Открыть расходы месяца».
6. Проверка созданного черновика в общем списке расходов.

## Проверенный E2E-сценарий

В изолированной локальной среде для `Axelio E2E Lounge` создано активное правило `Аренда склада`: фиксированная сумма `135 000,00 ₽`, дата старта `2026-10-01`, день месяца `5`, категория `Аренда`, поставщик `Local Partner`, способ оплаты `СБП`.

После нажатия `Сгенерировать за месяц` для `2026-10` интерфейс показал:

- `Месяц 2026-10 · создано 1 · пропущено 0`;
- уведомление `Создано: 1, обновлено: 0, пропущено: 0`;
- строку результата `Аренда`, `2026-10-05 · Черновик`, `135 000,00 ₽`.

В списке расходов появился документ с признаками `Черновик`, `Регулярный`, `Сгенерирован 2026-10-01`, датой `2026-10-05`, полной суммой `135 000,00 ₽` и комментарием `[REGULAR] Аренда склада · 2026-10 · фикс`. В базе подтверждены связь с правилом, статус `DRAFT`, `generated_for_month = 2026-10-01` и сумма `13 500 000` копеек.

## Визуальная сборка

- `build_guide.py` воспроизводимо собирает все PNG через Pillow.
- Шаговые слайды используют фиксированную сетку одобренной серии: одинаковые координаты номера, `ШАГ N`, заголовка, пояснения, UI-рамки и нижней подсказки.
- Стрелки не используются: целевой месяц, правило и кнопки выделены рамкой.
- Стили кнопок соответствуют интерфейсу: `Сгенерировать за месяц` — обычная вторичная кнопка; `Открыть расходы месяца` — subtle; `Подтвердить` — обычная кнопка; `Удалить` — danger.
- Все изображения программно проверяются на RGB и 1080×1080; UI-строки сверяются с текущим кодом.
