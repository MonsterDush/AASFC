# Как сравнить начисления с предыдущим периодом?

- Дата: 2026-08-29
- Функция: автоматическое сравнение начислений за равные по длине периоды
- Формат: Instagram-карусель, 7 отдельных изображений 1080×1080
- Следующая рекомендуемая тема: «Как настроить выплаты ФОТ?»

## Реальный пользовательский маршрут

1. Страница заведения → блок «Финансы» → «Начисления».
2. В блоке «Период начислений» выбрать «Период».
3. Указать даты и нажать «Показать».
4. Раскрыть карточку «Сравнение начислений».
5. Оставить режим «Авто».
6. Прочитать дельты под ключевыми показателями начислений.

Маршрут проверен в локальном E2E Axelio на синтетических данных. Производственные действия не выполнялись. Расчёт зарплаты не запускался, а настройки сравнения не сохранялись; локальный тестовый профиль мог обновить только язык интерфейса при входе.

## Использованные реальные экраны и результат

- `frontend/app-venue.html` — вход в раздел «Начисления» из блока «Финансы»;
- `frontend/owner-payroll.html` и `frontend/owner-payroll.js` — выбор диапазона, карточка сравнения и показатели;
- `frontend/app/period-comparison.js` — автоматический выбор предыдущего периода такой же длины;
- локальный E2E-экран `owner-payroll.html?venue_id=1&period_mode=range&date_from=2026-08-16&date_to=2026-08-31&compare_mode=auto&lang=ru`.

В E2E выбран период `2026-08-16 — 2026-08-31`. Режим «Авто» подобрал период сравнения `2026-07-31 — 2026-08-15` и показал реальные дельты:

- «Фонд оплаты труда» — `705 435,59 ₽`, `+21,7% · +125 635,60 ₽ к предыдущему периоду такой же длины`;
- «Сотрудников в расчёте» — `9`, `0% · 0 к предыдущему периоду такой же длины`;
- «Среднее начисление» — `78 381,73 ₽`, `+21,7% · +13 959,51 ₽ к предыдущему периоду такой же длины`;
- «Среднее за смену» — `5 075,08 ₽`, `+15,5% · +682,66 ₽ к предыдущему периоду такой же длины`.

## Визуальная сборка

- Слайды собраны кодом в `build_guide.py` через Pillow.
- Декоративная иллюстрация обложки создана встроенным ImageGen в режиме по умолчанию. Промпт: две тёмные карточки начислений, абстрактные столбики и баланс сравнения в фирменной сине-фиолетовой палитре, без текста и логотипов. Иллюстрация не подменяет интерфейсные экраны.
- Рабочие фрагменты реконструированы по текущему UI Axelio. «Показать» показана как обычная вторичная `.btn`, «Авто» — как активный элемент сегментированного переключателя, «Настроить» — как бейдж в заголовке карточки, а не как придуманная primary-кнопка.
- Инструкционные стрелки не используются: на каждом шаге достаточно одной фиолетовой рамки вокруг целевого элемента.
- На шагах 1–5 сохранена сетка серии: номер шага `(64, 50, 124, 110)`, «ШАГ N» `(145, 64)`, заголовок `(64, 137)`, пояснение `(64, 230)`, UI-зона `(60, 315, 1020, 930)`, нижняя подсказка `y=950`.
- Геометрия сопоставлена с `content/manuals/2026-08-13-invite-employee` и программно проверяется против общей сетки серии.
