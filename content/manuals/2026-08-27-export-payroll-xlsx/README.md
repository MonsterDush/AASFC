# Как выгрузить начисления в XLSX?

- Дата: 2026-08-27
- Функция: экспорт расчёта зарплаты в книгу XLSX
- Формат: Instagram-карусель, 5 отдельных изображений 1080×1080
- Следующая рекомендуемая тема: «Как сравнить начисления с прошлым периодом?»

## Реальный пользовательский маршрут

1. Страница заведения → блок «Финансы» → «Начисления».
2. «Расчёт зарплаты» → «Период начислений» → выбрать «Месяц» или «Период».
3. Нажать «Экспорт XLSX».
4. Axelio скачивает книгу с расчётом за выбранный период.

Маршрут проверен в локальном E2E Axelio на синтетических данных. Производственные действия не выполнялись. Экспорт является read-only операцией: данные приложения не изменялись.

## Использованные реальные экраны и результат

- `frontend/app-venue.html` — вход в раздел «Начисления» из блока «Финансы»;
- `frontend/owner-payroll.html` и `frontend/owner-payroll.js` — выбор периода и кнопка «Экспорт XLSX»;
- `backend/app/routers/venue_revenue_exports.py` — формирование ссылки и имени файла;
- `backend/app/services/xlsx_export.py` — фактическая структура книги;
- локальный E2E-экран `owner-payroll.html?venue_id=1&month=2026-08&lang=ru`;
- скачанный файл `payroll_Axelio_E2E_Lounge_2026-08.xlsx`.

Кнопка «Экспорт XLSX» была нажата в локальном E2E. Запросы `payroll/export-link` и `payroll/export` завершились с кодом 200. Фактическая книга проверена: листы «Сводка», «Начисления», «Разбор»; период `2026-08`; 9 строк начислений; итог `1 285 235,58 ₽`.

## Визуальная сборка

- Слайды собраны кодом в `build_guide.py` через Pillow.
- Декоративная иллюстрация обложки создана встроенным ImageGen в режиме по умолчанию; она не подменяет интерфейсные экраны.
- Рабочие фрагменты реконструированы по текущему UI Axelio: «Экспорт XLSX» показана как обычная `.btn.ghost`, а «Рассчитать» — как синяя `.btn.primary`.
- Инструкционные стрелки не используются: на каждом шаге достаточно одной фиолетовой рамки вокруг целевого элемента.
- На шагах 1–3 сохранена сетка серии: номер шага `(64, 50, 124, 110)`, «ШАГ N» `(145, 64)`, заголовок `(64, 137)`, пояснение `(64, 230)`, UI-зона `(60, 315, 1020, 930)`, нижняя подсказка `y=950`.
- Геометрия сопоставлена с `content/manuals/2026-08-13-invite-employee` и программно проверяется против общей сетки серии.
