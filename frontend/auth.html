Вход по телефону
Основной сценарий — вход по номеру телефона и паролю. Звонок нужен только для первой настройки номера и для сброса пароля. SMS можно временно отключать через настройку на backend.
Первичная настройка
Подтверди номер звонком и сразу задай пароль для следующих входов.
Вход через Telegram
Дополнительный способ входа для браузера. Мы не встраиваем Telegram в страницу: по кнопке ниже откроется бот, где нужно подтвердить вход, а эта страница завершит авторизацию автоматически.
Telegram пока не используется. Запусти вход вручную по кнопке ниже.
Открыть бота
Если бот открывается впервые, нажми Start / Запустить, затем кнопку подтверждения в сообщении от бота.
Что дальше
После входа тебя вернёт на страницу, с которой запрашивалась авторизация.
Правила пароля
Пароль должен быть не короче 8 символов и содержать хотя бы одну букву и одну цифру.
