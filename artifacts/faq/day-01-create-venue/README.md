# Выпуск 01 — создание заведения

Готовый комплект первого материала серии «Axelio: как это работает».

- `post.md` — готовый текст сообщения с изображениями в нужном порядке;
- `carousel-v2/00-cover.png` — утверждённая светлая обложка в стиле продуктового help center;
- `carousel-v2/01-open-management.png` — переход через настройки с раскрытым пунктом «Управление заведениями»;
- `carousel-v2/02-create-venue.png` — отдельная карточка кнопки создания;
- `carousel-v2/03-enter-name.png` — отдельная карточка ввода названия;
- `cover/` и `screenshots/` — предыдущая тёмная итерация материала;
- `raw-local/` — исходные снимки из изолированного E2E-окружения Axelio;
- `archive/v1/` — первая отклонённая версия обложки и DEMO-кадров;
- `make_carousel_v2.py` — воспроизводимая сборка утверждённой обложки и трёх карточек;
- `make_cover.py` и `make_screenshots.py` — сборка предыдущей итерации.

Интерфейсные кадры сделаны локально без DEMO-плашки. Нативное системное меню `select` не попадает в браузерный скриншот, поэтому на первой карточке оно восстановлено как документационная аннотация из реальных пунктов интерфейса. Пример названия в форме не отправлялся.
